# Coders Hub

複数の [Claude Code](https://claude.com/claude-code) のセッション（複数のアカウント `CLAUDE_CONFIG_DIR` を含む）を、**ブラウザの 1 つの画面で見て、指示の送信・許可と質問への応答ができる**ローカルアプリです。ターミナルを巡回せずに、どのセッションが許可待ち・質問待ちかに気づけます。

- Windows 向け。通信は、このパソコンの中だけ（`127.0.0.1`）です。外部には送りません
- Claude Code の公式の機能（フック・MCP・Channels）を使う、非公式のツールです。Anthropic の製品ではありません

## できること

| | |
|---|---|
| **一覧** | 全セッションを、アカウント → プロジェクト → セッションのツリーで表示。状態（許可待ち・質問待ち・返答待ち・作業中）を、色と札で表示。起動順の並び、折りたたみ、「操作できるものだけ」の絞り込み |
| **要対応に気づく** | 許可待ち・質問待ちの件数を、アカウントとプロジェクトの見出し、ブラウザのタブのタイトルに表示 |
| **指示の送信** | 返答待ちのセッションに、ブラウザから指示を送る。作業中に送った指示は、保留して、返答待ちになったときに渡す |
| **許可・質問への応答** | 許可プロンプトの許可・拒否、モデルからの質問（選択・自由入力）への回答を、ブラウザから行う。ターミナルで先に応答したときは、自動で閉じる |
| **会話の表示** | 選んだセッションの会話（発言・応答・ツールの使用・質問と答え）を、Markdown で整形して表示。上へスクロールすると、前の会話を読み込む |
| **スマホ幅** | 幅 800px 以下では、一覧と詳細を別画面にする |

指示の送信と、許可・質問への応答は、**操作モード**で起動した `claude` で使えます（下の「使い方」）。

## 入れ方（配布版。Node.js は要りません）

1. [リリース](https://github.com/takeshita-work/coders-hub/releases)から、`coders-hub-<バージョン>-win-x64.zip` をダウンロードして、展開します。`coders-hub.exe` を、好きな場所に置きます（置いたあとは、移動しないでください。設定に、この exe のパスを書きます）。
2. Windows の SmartScreen が警告したときは、「詳細情報」→「実行」を選びます（この exe は署名していません）。SHA-256 は、`SHA256SUMS.txt` と、次のコマンドの結果を見比べて確認できます。
   ```powershell
   Get-FileHash .\coders-hub.exe -Algorithm SHA256
   ```
3. 設定を表示します。
   ```powershell
   .\coders-hub.exe setup
   ```
   表示された内容を、claude に入れます。
   - **1. フック設定**: 使う claude の `settings.json`（アカウントごと）に追加します
   - **2. 一覧だけのモード / 3. 操作モード**: JSON を、`coders-hub.json`・`coders-hub-control.json` などの名前で保存します

## 使い方

1. claude を起動します。
   ```powershell
   # 一覧だけのモード（状態を見るだけ）
   claude --mcp-config coders-hub.json

   # 操作モード（指示の送信・許可と質問への応答もできる）
   claude --mcp-config coders-hub-control.json --dangerously-load-development-channels server:coders-hub
   ```
   操作モードは、`--mcp-config` の設定（`--channel`）と、開発用フラグの**両方**がそろったときだけ有効です。フラグを付け忘れると、指示は黙って捨てられます。
2. 最初の claude のセッションが、Hub（画面を配信する部分）を自動で起動します。手動で起動するときは、`coders-hub.exe` を実行します（ウィンドウを閉じると止まります）。
3. ブラウザで <http://127.0.0.1:47766/> を開きます。Edge / Chrome の「アプリとしてインストール」で、専用のウィンドウにもできます。

### ポート

内部 API（フック・チャネルサーバー → Hub）が `47765`、画面が `47766` です。変えるときは、設定ファイル `%APPDATA%\coders-hub\config.json` を作ります（Hub・フック・チャネルサーバーのすべてが、同じファイルを読みます）。

```json
{ "internalPort": 47765, "uiPort": 47766 }
```

- どちらか片方だけでも書けます。環境変数 `CODERS_HUB_INTERNAL_PORT`・`CODERS_HUB_UI_PORT` を設定すると、ファイルより優先します。
- 変えたあとは、動いている Hub を止めて、`claude` を起動し直します。画面を「アプリとしてインストール」したときは、ポートを変えない前提です（アプリは、インストールした URL を開きます）。

### 更新・アンインストール

- **更新**: 新しいリリースの zip を展開し、`coders-hub.exe` を置き換えます（動いている Hub は、先に止めます）。
- **アンインストール**: claude の設定から、追加したフックと MCP の設定を消し、`coders-hub.exe` を削除します。

### 困ったとき

- 一覧に出ない: <http://127.0.0.1:47765/health> が `ok` を返すか確認します。claude で `/mcp` を開き、`coders-hub` が connected か確認します。
- 画面が開かない: Hub が動いていません。claude を起動するか、`coders-hub.exe` を実行してください。
- 「すでに使われています」: 別のアプリがポートを使っています。設定ファイルでポートを変えてください。
- 許可待ちなのに、画面に許可要求が出ない: 操作モード（開発用フラグ付き）で起動していない可能性があります。ターミナルで応答してください。

## 仕組み

```
claude ──(フック)────────────► Hub 本体 ══ WebSocket ══► ブラウザの画面
claude ◄──stdio──► チャネルサーバー ─(ロングポーリング)──►  （127.0.0.1:47766）
                      （指示・許可の応答を claude へ渡す）
```

- **フック**: セッションの状態の変化（作業中・返答待ち・許可待ちなど）を Hub へ送ります。
- **チャネルサーバー**: claude が起動する MCP サーバー。生存確認と、指示・許可の応答の受け渡しをします。Hub が動いていなければ、起動します。
- **Hub 本体**: 状態を、メモリの中だけで管理します（保存しません）。画面を配信し、WebSocket で変化を即座に届けます。会話は、画面から要求されたときに、claude の会話ログ（JSONL）の必要な分だけを読んで返し、保持しません。

## セキュリティとプライバシー

- `127.0.0.1` だけで待ち受けます。外部には公開しません。画面からの書き込み・会話の取得は、`Host`・`Origin`・独自ヘッダーを検査して、他のサイトのページから使えないようにしています。
- 状態・指示・会話の履歴は、保存しません（再起動すると、動いているセッションが自動で戻ります）。
- 通知は、画面内の表示だけです（ブラウザ通知・外部への通知はしません）。

## 開発者向け

Node.js 22 以上が要ります。仕様駆動開発（SDD）で進めており、**仕様は `specs/` が唯一の正**です（入口: [`specs/README.md`](specs/README.md)、開発ルール: [`AGENTS.md`](AGENTS.md)）。

```powershell
npm install
npm run build        # 画面をビルド（dist/web）
npm start            # Hub を起動（http://127.0.0.1:47766/）
npm test             # テスト（node:test）
npm run build:exe    # 配布版の exe を作る（dist/exe/coders-hub.exe）
npm run package      # 配布物の zip を作る（dist/release/）
node scripts/print-setup.mjs   # claude に入れる設定を表示（開発版。node で起動する形）
```

セットアップの詳細（フック・MCP・操作モード・ポート・アプリとしてのインストール）は、[`docs/setup.md`](docs/setup.md) にあります。

主なフォルダ:

| | |
|---|---|
| `specs/` | 仕様（要件・設計・機能ごとの spec・plan・tasks・ADR） |
| `src/hub/` | Hub 本体（状態管理・API・WebSocket・会話の読み取り） |
| `src/hook/`・`src/channel/` | フックとチャネルサーバー（claude が起動する） |
| `src/web/` | 画面（React。esbuild でビルド） |
| `src/cli/` | 配布版（exe）の入口 |
| `docs/` | セットアップ手順・調査メモ |
