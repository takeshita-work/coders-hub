## 2. 実機の確認（T7-2）

**あなたの操作が必要。** 結果の欄に ○／×／メモを書く。

### 準備
- [ ] 画面をビルドする: `npm run build`
- [ ] 動いている Hub を止める（新しいコードで起動し直すため）。止めると、次に起動する `claude` のチャネルサーバーが、新しい Hub を自動で起動する
  ```powershell
  Stop-Process -Id (Get-NetTCPConnection -LocalPort 8765 -State Listen).OwningProcess
  ```
- [ ] `.mcp.json` の `coders-hub` に `--channel` を足してある（操作モード）。確認: `node scripts/print-setup.mjs` の「3. 操作モード」と同じ内容か
- [ ] 操作モードで起動する（このフォルダで）
  ```powershell
  C:\Users\yuya\.local\bin\claude_scripts\claude_start.ps1 takeshita.work --dangerously-load-development-channels server:coders-hub
  ```
  警告画面が出たら承認する。`/mcp` で `coders-hub` が connected であること
- [ ] ブラウザで `http://127.0.0.1:8766/` を開く（必要なら Ctrl+F5）

### 手順

| # | 操作 | 期待する結果 | 結果 |

| 1 | 返答待ちのセッションの行で「指示を送る」を押し、`1+1 はいくつですか` を送る | 行に「届きました」が 3 秒以内に出る。セッションが答える。ターミナルにも `← coders-hub: …` と表示される（AC-002-1, 002-2, 002-6, 002-7, 005-2） |○（3 秒以内に「届きました」。ターミナルにも `← coders-hub:` と表示された） |
