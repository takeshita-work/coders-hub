# 004 会話の表示

- ステータス: Approved（2026-10-11）
- 対応要件: REQ-007
- 関連 NFR: NFR-003, NFR-008, NFR-009
- 関連 ADR: 0007（会話ログの定期確認）、0012（書き込み API の保護）、0015（画面構成）、0016（会話の読み方）、0017（Markdown の整形）、0029（ツールの行に、コマンド・ファイル名を出す）
- 画面の方針: `../../20-design/screens/README.md`、`../006-dashboard-layout/spec.md`（会話の領域）

## 目的
セッションの詳細で、そのセッションの**会話**（利用者の発言と Claude の応答）を、直近から**さかのぼって**読めるようにする。許可・質問・指示を送る前に、いま何をしているかを画面で確かめられるようにする。

機能 006 で用意した「会話の領域」に、会話の本文を出す。検索やエクスポートではなく、**直近から、必要なだけ読み進める**ためのもの（REQ-007）。

## 用語
`../../00-product/glossary.md` に従う。「会話ログ」は、`claude` が書く JSONL（`<CLAUDE_CONFIG_DIR>\projects\<プロジェクト>\<session-id>.jsonl`）。

## 振る舞い

### 表示する内容
- 詳細を開くと、会話の領域に、直近の会話が時系列（上が古い、下が新しい）で表示される。既定は直近 20 件（利用者の発言・Claude の応答・質問の数。ツールの行は数えず、その間に含める）
- 表示するもの
  - **利用者の発言**: 利用者が `claude` に送った文章。右寄せ。ダッシュボードから送った指示も含み、そのときは「ダッシュボードから」の目印を付ける
  - **Claude の応答**: 応答の文章（テキスト）。左寄せ
  - **ツールの使用**: 閉じた 1 行（ツール名・要点・結果: 成功／拒否／エラー／実行中・時刻）。要点は、実行したコマンドや、変更したファイル名など。開くと、要点の全文（コマンド全文・フルパスなど）。**出力（結果の中身）は出さない**（ADR 0029）。要点と全文が同じ行は、開閉しない
  - **ツールのグループ**: 連続した 2 件以上のツールの行は、1 つのグループにまとめる。閉じた 1 行は、件数・ツール名（回数）・結果の内訳・時刻の範囲。開くと、個別の行が並び、各行も開閉できる。間に、発言・応答・質問・結果の行が入れば、別のグループになる。1 件だけの行は、まとめない。開閉の状態は、会話が更新されても、保たれる
  - **モデルからの質問（`AskUserQuestion`）**: 質問文と、選ばれた答え
- 表示しないもの: 思考（thinking）、ツールの出力（結果の中身）、サブエージェントの会話（`isSidechain`）、システムの記録（フックの結果、コマンドの記録、`isMeta` の注入など）、画像。ただし、ダッシュボードから送った指示（`origin.kind` が `channel`。`isMeta` だが利用者の発言として扱う）は表示する
- 各発言に、時刻（時:分）を小さく付ける
- **Claude の応答は、Markdown として整形して表示する**（見出し・箇条書き・コードブロック・インラインコード・表・引用・区切り線・強調・リンク。改行は保つ）。文章の中の HTML は、解釈せず、文字として表示する。リンクは `http(s)`・`mailto` だけで、新しいタブで開く。画像は読み込まない。利用者の発言は、書いたとおりの文字で表示する（ADR 0017）
- 1 件が長いときは、4,000 文字までを表示し、超えた分は省略する（「…（以下省略）」）
- **上の端の近くまでスクロールすると、前の 20 件が自動で読み込まれる**（ボタンは使わない）。**件数の上限はない**（会話ログの先頭まで読める）。読み込みは 20 件ずつ、要求のたびに必要な分だけ読む。読み込んでいる間は、「前の会話を読み込んでいます…」と出す。内容が画面に満たず、スクロールできないときは、満たすまで自動で読み込む。先頭まで読んだら、止まる

### 更新
- 詳細を開いている間、新しい発言・応答が、3 秒以内に会話に出る（作業中は、続けて増える）
- 変更がないときは、同じ内容を何度も送らない
- 詳細を開いていないセッションの会話は、読まない
- スクロールは機能 006 のとおり（開いたときと、新しい内容が増えたときは一番下へ。上を読んでいるときは動かさない）

### 機能 002・003 との関係（機能 006 の会話の領域）
- ダッシュボードから送った指示は、会話ログに利用者の発言として現れる。ログに現れたら、画面の「届きました」の行は出さない（二重に出さない）。保留中の指示は、まだログにないので、これまでどおり「保留中」で出す
- 許可・質問の結果の行（「許可しました」など。機能 006）は、会話の中の、**起きた時刻に合った位置**に出す（ログの発言・ツールの間に入る）。ブラウザのメモリだけに持つので、再読み込みで消える。送った指示（保留中・届きました、など）も、同じく時刻の順に並ぶ

### 読めないとき
- 会話ログが見つからない・読めない・形式が想定外のとき、「会話を読み込めません」と表示する。**状態の表示、許可・質問への応答、指示の送信など、ほかの機能は影響を受けない**（NFR-008）
- 壊れた行・途中で切れた行は飛ばす

### 保持しない（NFR-009）
- 会話の本文は、Hub 本体のメモリにも保存しない。画面から要求されたときに、ログから必要な分だけを読んで返し、返したら捨てる
- ブラウザには、表示している間だけ持つ。ブラウザに保存しない（localStorage を使わない）

## 受け入れ条件

AC の番号は、要件 REQ-007 に対応する。

### 表示
- AC-007-1: 詳細を開くと、そのセッションの直近 20 件（発言・応答・質問の数。ツールの行は数えず、その間に含める）が、会話の領域に時系列で表示される
- AC-007-2: 利用者の発言（右寄せ）と Claude の応答（左寄せ）が、見た目で区別できる。時刻が付く
- AC-007-3: ダッシュボードから送った指示が、利用者の発言として表示され、「ダッシュボードから」の目印が付く。ログに現れたあとは、「届きました」の行が出ない。保留中の指示は「保留中」のまま
- AC-007-4: ツールの使用は、閉じた 1 行（ツール名・実行したコマンド／ファイル名・成功／拒否／エラー／実行中・時刻）で表示される。開くと、全文が見える。要点と全文が同じ行は、開閉しない。ツールの出力・思考は、表示されない
- AC-007-5: `AskUserQuestion` は、質問文と選ばれた答えが表示される
- AC-007-6: Claude の応答が Markdown として整形される（見出し・箇条書き・コード・表・引用・リンク・強調）。文章の中の HTML（スクリプト・イベント属性・iframe など）は、解釈されず、文字として出る。`javascript:` などのリンクはリンクにならず、画像は読み込まれない。利用者の発言は、書いたとおりの文字で出る。改行が保たれる
- AC-007-7: 4,000 文字を超える発言は、省略して表示される
- AC-007-8: 上の端の近くまでスクロールすると、前の 20 件が自動で加わり、いま見ている位置は動かない。件数の上限はなく、会話ログの先頭まで読める。先頭まで読んだら、それ以上は読み込まない。内容が画面に満たないときは、満たすまで自動で読み込む
- AC-007-9: サブエージェントの会話・システムの記録は、表示されない

### 更新
- AC-007-10: 詳細を開いている間に新しい発言・応答がログに書かれると、3 秒以内に会話に出る（NFR-003）
- AC-007-11: 変更がないとき、会話の再送は行われない（条件つきの取得で、本文を返さない）
- AC-007-12: 詳細を開いていないセッションの会話ログは、読まれない

### 保持と安全
- AC-007-13: Hub は、会話の本文を、メモリにも保存しない（要求ごとに読んで返す。キャッシュしない。NFR-009）
- AC-007-14: ブラウザは、会話の本文を、localStorage などに保存しない
- AC-007-15: 会話の取得は、書き込み API と同じ保護（`Host`・`Origin`・独自ヘッダー。ADR 0012）を通らないと 403 になる。読むファイルは、Hub が知っているセッションの会話ログだけ（クライアントからパスを渡せない）
- AC-007-16: Hub がセッションの会話ログの場所を受け取っていなくても（Hub の再起動後など）、`<アカウント>/projects/*/<session-id>.jsonl` から見つけて表示できる

### 失敗と性能
- AC-007-17: 会話ログが見つからない・読めない・形式が想定外のときは、「会話を読み込めません」と表示され、状態・許可・質問・指示の機能は影響を受けない（NFR-008）
- AC-007-18: 壊れた行・途中で切れた行があっても、読める分は表示される
- AC-007-19: 10 MB を超える会話ログでも、1 回の取得（20 件）は、必要な分だけを読み、1 秒以内に応答する。さかのぼるほど読む位置が前に進むだけで、毎回ログ全体は読まない
- AC-007-21: 画面の幅が狭くても（スマホ幅を含む）、会話の内容が切れず、すべて表示される（長い 1 語・URL・パスは折り返す。コードブロック・表は、その中で横にスクロールする）
- AC-007-22: 連続した 2 件以上のツールの行が、1 つのグループになる。閉じた 1 行に、件数・ツール名（回数）・結果の内訳・時刻の範囲が出る。開くと、個別の行が並び、各行も開閉できる。1 件だけの行は、まとめない。間に発言・応答・結果の行が入れば、別のグループになる
- AC-007-23: ツールの行・グループの開閉の状態が、会話の更新（再取得）のあとも、保たれる
- AC-007-24: Hub が返すツールのメッセージに、要点（`tool.summary`）と全文（`tool.detail`）が入る（Bash・Read・Edit・Write・NotebookEdit・Grep・Glob・WebFetch・WebSearch・Task・Agent。ADR 0029 の表のとおり）。4,000 文字で切る。要点が取れないツールは、どちらもなし。ツールの出力は、返さない
- AC-007-25: 許可・質問の結果の行と、送った指示が、会話の中の、起きた時刻に合った位置に入る（ログの発言・ツールの間）。再読み込みで消えてよい
- AC-007-20: 読み込んだ件数が増えても、画面の操作（スクロール・入力・許可・質問への応答）が重くならない（件数が多いときの描画の工夫は、plan で決める）

## 対象外
- 検索・エクスポート・全文の一括表示（さかのぼって読むことはできる）
- 思考、ツールの入力・出力、画像、サブエージェントの会話の表示
- コードのシンタックスハイライト（言語ごとの色付け）
- 会話の保存（NFR-009）
- 過去のセッション（終了したセッション）の会話の閲覧（一覧に出ているセッションだけ）
- モデル名・使用率の表示（別の検討。会話ログの応答にはモデル名が入っていることを実機で確認した。`../../10-requirements/open-questions.md`）

## 決定済み
- Claude の応答は Markdown として整形する（2026-10-11 の要望。ADR 0017）。利用者の発言は、そのままの文字
- 前の会話は、上へスクロールしたときに自動で読み込む（「さらに表示」のボタンはやめた）
- ツールの入力（`tool_use.input`）から、要点と全文を取り出す（ADR 0029）。ツールの出力は、出さない
- スラッシュコマンド（`/clear` など）の記録は、会話に出さない（確認済み）
- 会話は、要求のたびに会話ログから読み、Hub は保持しない。取得は書き込み API と同じ保護を付ける（ADR 0016）
- 「さらに表示」の件数に上限は設けない（確認済み。REQ-007 を「直近から、さかのぼって参照できる」に改めた）

## 未決事項
- 1 件の省略の長さ（4,000 文字）と、最初の件数・1 回の追加の件数（20 件）が適切か（実装後に調整）
- 件数がとても多くなったときの画面の負担（古い分の折りたたみなど）。実機で、どの程度から重くなるかを見て決める
- （決定済み）結果の行（許可・質問）と、会話のツール行・質問の行の重なり → 結果の行を、時刻の順に、会話の中に入れる（AC-007-25）
- ログの形式が変わったとき（NFR-008）の検知（読めたのに、表示件数が 0 になる、など）の扱い
