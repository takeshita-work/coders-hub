## 2. 実機の通し確認（T6-2）

**あなたの操作が必要。** 結果の欄に ○／×／メモを書く。

### 準備
- [ ] 前の実験の仮 Hub（`probe-hub.mjs`）を止める（ポート 8765 が空くこと）
- [ ] `npm run build`
- [ ] このプロジェクトの `.mcp.json`（`coders-hub`）と `.claude/settings.local.json`（`src/hook/hook.mjs`）が入っていること。プロジェクトの設定なので、`CLAUDE_CONFIG_DIR` が違っても、このフォルダで起動すれば同じ設定が使われる
- [ ] ブラウザで `http://127.0.0.1:8766/` を開く（Hub が未起動なら、手順 2 で最初の `claude` が起動する）

### 手順

| # | 操作 | 期待 | 結果 |
