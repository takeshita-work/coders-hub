# セキュリティ・外部公開

- ステータス: Draft（公開方式は未決。ADR 0005）

## 前提
外部公開は「外から PC 上でコマンドを実行できる入口」を作るのと同じ。

## 公開範囲

| 待ち受け先 | 用途 | 外部公開 |
|---|---|---|
| `127.0.0.1:8765` | チャネルサーバー・フックとの内部通信 | しない |
| `127.0.0.1:8766` | ダッシュボードと画面用 API | 公開方式による |

## 方式の候補

| 方式 | 内容 | 備考 |
|---|---|---|
| Cloudflare Tunnel + Access | ポート開放なしで公開。Access で認証（自分のみ・MFA 必須・短めのセッション有効期間） | 本体でも `Cf-Access-Jwt-Assertion` の JWT を検証（設定ミスへの保険） |
| Tailscale | 公開 URL を作らず、自分の端末だけのプライベートネットワークでアクセス | 自分専用ならこちらがシンプルで安全 |

## 追加の対策（検討）
- 外部からの許可応答を「拒否のみ」に絞る

## 技術的な注意
- Cloudflare 経由のリクエストは約 100 秒で 524 エラー。画面側のロングポーリングは 30 秒程度、または WebSocket を使う
- PC がスリープすると全体が止まる
