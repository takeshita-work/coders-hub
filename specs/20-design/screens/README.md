# 画面仕様

- ステータス: Draft（一覧画面の方針は確定。詳細レイアウトは `30-features/001-session-list` で詰める）

## 一覧画面（MVP）

### 構成
- 画面上部: **要対応件数のサマリー**（例: 許可待ち 2・質問待ち 1・返答待ち 3）。ブラウザのタブのタイトルにも反映する
- 状態での絞り込み（全て／要対応のみ）
- 本体: **アカウント（`CLAUDE_CONFIG_DIR`）ごとのグループ**。グループは折りたたみ可能
- 対象は最大 30 セッション（NFR-002）、PC の Chrome / Edge（NFR-010）

### 並び順
- グループ内は**状態順**: 許可待ち → 質問待ち → 返答待ち → 作業中。同じ状態の中は、その状態になった時刻が新しい順
- 要対応のセッションが常に上に来る

### 1 行の表示項目
| 項目 | 備考 |
|---|---|
| 状態 | 作業中／返答待ち／許可待ち／質問待ち。作業中以外は強調表示（REQ-010） |
| 状態の経過時間 | 「返答待ち 5 分」のように、その状態になってからの時間 |
| プロジェクト | 作業ディレクトリ（cwd） |
| 直近の発言 | 最後のプロンプト。`UserPromptSubmit` フックの入力から取得する（JSONL は使わない） |
| セッション ID（短縮） | 同じプロジェクトに複数セッションがあるときの区別用 |

### 動作
- 状態の反映は WebSocket で即時に行う（NFR-003: 3 秒以内）
- 通知は画面内の表示のみ。ブラウザ通知・スマホ通知はしない
- 折りたたんだグループにも、要対応のセッション件数を表示する

## 決定済み
強調表示・保存・省略・経過時間の形式などは `30-features/001-session-list/spec.md`「画面で決めたこと」に記載。
