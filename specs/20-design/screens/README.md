# 画面仕様

- ステータス: Draft（機能 006 で詳細化。判断は ADR 0015。見た目の基準は試作 `./mockup/index.html`）

## 全体の構成
- **左にサイドバー（セッションのツリー）、右にメイン（選んだセッションの詳細）**
- 幅 800px 以下（スマホ）では、一覧（サイドバー）と詳細を別画面にする。詳細の見出しに戻るボタン（「‹」）を出す
- ページ全体はスクロールしない。サイドバーとメインがそれぞれスクロールする。メインのスクロールバーは画面の右端に、上から下まで出す
- 対象は最大 30 セッション（NFR-002）、PC の Chrome / Edge、およびスマホ幅の表示（NFR-010）
- ライト・ダークの両方に対応する

## サイドバー

### 構成
- 見出しの行: 「Coders Hub」と、右端の「フィルター・ソート」ボタン（開くとパネル。絞り込み中は印）
- パネル: 「操作できるものだけ」（スイッチ）、プロジェクトの並び（昇順／降順）、セッションの並び（早い順＝昇順／遅い順＝降順）。押すごとに切り替える
- ツリー: **アカウント（`CLAUDE_CONFIG_DIR`）の帯 → プロジェクト → セッション**。アカウントとプロジェクトは折りたたみ可能。帯はサイドバーの左右いっぱい

### 並び順
- 状態では並べ替えない（位置が状態で動かない）
- アカウント: 起動が最も早いセッションを持つ順。プロジェクト: 名前順。セッション: 起動順（`startedAt`）
- 状態は、行の色と札、帯・プロジェクトの件数で分かる

### セッションの行（2 行の高さ）
| 項目 | 備考 |
|---|---|
| セッション ID（短縮） | 1 行目 |
| 状態の経過時間 | 1 行目。その状態になってからの時間 |
| 状態の札 | 1 行目。許可／質問／作業。**返答待ちは札なし**。操作モードでないセッションは、右端に「閲覧のみ」 |
| 直近の発言 | 2 行目。`UserPromptSubmit` フックの入力から取得する（JSONL は使わない） |

- 左の太線の色＝状態（許可待ち＝オレンジ、質問待ち＝紫、返答待ち＝グレー、作業中＝青）
- 背景＝操作できるか（できる＝白、できない＝グレー）
- 短い許可要求には、行の右に「許可」ボタン（拒否は出さない）

## 詳細（メイン）
- 見出し: プロジェクト名とアカウント名。固定せず、会話と一緒にスクロールする
- 会話の領域（時系列）: 会話の本文（機能 004）、応答待ちの許可要求・質問のカード（末尾）、応答後の結果の行（状態の色で右寄せ）、送った指示（保留中／届きました）
- 下部（固定）: メッセージ入力欄（送信ボタンなし。Enter で送信、Shift+Enter で改行。1 行から始まり、20 行でスクロール）。その下に状態の行（ID・経過時間・状態の札）。一番下から離れているときは「一番下へ」ボタン
- 操作モードでないセッション: 入力欄を無効にして「閲覧のみ」と表示する

## 動作
- 状態の反映は WebSocket で即時に行う（NFR-003: 3 秒以内）
- 通知は画面内の表示のみ。ブラウザ通知・スマホ通知はしない。ブラウザのタブのタイトルに、要対応（許可待ち・質問待ち）の件数を出す
- 状態での絞り込み、検索、件数サマリーはない（ADR 0015）
