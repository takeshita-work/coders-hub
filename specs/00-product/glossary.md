# 用語集

- ステータス: Draft

| 用語 | 意味 |
|---|---|
| Coders Hub | 本アプリの名前。リポジトリ・MCP サーバー名は `coders-hub`、短縮コマンドは `chub` |
| Hub 本体 | セッション一覧・状態管理・指示の振り分け・許可応答・ダッシュボードを担う Node.js ローカルサーバー |
| アカウント | 1 つの `CLAUDE_CONFIG_DIR`。設定・履歴が分かれる単位 |
| セッション | ターミナルで動く 1 つの対話的な `claude` CLI プロセス。`session_id` で識別する（VS Code 拡張・`--bg` は対象外） |
| プロジェクト | セッションの作業ディレクトリ（cwd） |
| チャネルサーバー | セッションごとに Claude Code が起動する MCP サーバー（`channel.mjs`）。Hub 本体とセッションをつなぐ |
| Channels | Claude Code の機能。外部からセッションへメッセージを送る仕組み（research preview） |
| フック | Claude Code のイベント（`Stop` など）で起動するスクリプト。状態変化を Hub 本体へ通知する |
| asyncRewake | フックの非同期実行オプション。exit code 2 でセッションを起こせる。指示送信の代替方式 |
| 作業中 | ユーザーの入力を受けて Claude が処理している状態（`UserPromptSubmit` 〜 `Stop`） |
| 返答待ち | 応答完了（`Stop`）後、ユーザーの入力を待っている状態 |
| 許可待ち | ツール実行の許可プロンプトが出て、応答を待っている状態 |
| 質問待ち | モデルが質問（`AskUserQuestion`）をして、利用者の回答を待っている状態。ツールの許可ではない（ADR 0010） |

セッションの状態は「作業中／返答待ち／許可待ち／質問待ち」の 4 つ。人の応答で止まっている 3 つ（許可待ち・質問待ち・返答待ち）を「要対応」と呼ぶ。セッションが閉じたら一覧から外す。
| 指示 | アプリからセッションへ送るメッセージ（通常のユーザープロンプトとして扱われる） |
| 保留 | セッションが作業中・許可待ち・質問待ちのときに送られた指示を Hub 本体で預かり、返答待ちになったときに 1 件ずつ渡すこと（ADR 0013） |
| 操作モード | チャネルサーバーを `--channel` 付きで起動し、`claude` に開発用フラグを渡して起動したセッション。指示の送信・許可応答ができる（ADR 0011）。そうでない起動は「一覧だけのモード」 |
| JSONL | セッションの会話ログ（`<CLAUDE_CONFIG_DIR>\projects\...\<session-id>.jsonl`） |
