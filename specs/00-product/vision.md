# Vision

- ステータス: Draft

## 課題
複数アカウント（`CLAUDE_CONFIG_DIR`）・複数セッションで Claude Code を同時に使うと、どのセッションが返答待ち・許可待ち・質問待ちか分からず、ターミナルを巡回して確認することになる。

## 目的
全セッションの状態を一か所で見て、そこから指示の送信と許可プロンプトへの応答ができるようにする。外出先からも使えるようにする。

## 想定ユーザー
- 自分専用（個人利用）
- 複数の `CLAUDE_CONFIG_DIR` を使い分け、複数セッションを並行して動かす開発者
- 利用環境: Windows、ターミナル（VS Code 統合ターミナルなど）から実行する対話的な Claude Code CLI
- 対象外の利用形態: VS Code 拡張のパネル、`claude --bg`（バックグラウンド）。これらは扱わない

## 成功の基準
優先度の高い順。

1. **気づける**: 返答待ち・許可待ち・質問待ちのセッションに、巡回せずに気づける（状態の一覧が中心）
2. ターミナルに戻らずに指示を送れる・許可に応答できる
3. ターミナルでの通常操作を邪魔しない（共存できる）

## 将来の拡張
- Claude Code 以外の AI コーディングツールへの対応は、設計だけ考慮する。MVP は Claude Code のみ。ツールごとの接続部品を差し替えられる構造にしておく。
