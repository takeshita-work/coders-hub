# 0021: 設定ファイル（config.json）は、coders-hub.exe と同じフォルダに置く

- ステータス: Accepted
- 日付: 2026-10-12

## 背景
ADR 0019 では、設定ファイルを `%APPDATA%\coders-hub\config.json` に置き、「exe の隣には置かない（更新で exe を置き換えても残すため）」とした。

その後、次の点が分かった（ユーザーの要望、2026-10-12）。

- 配布版は、zip を展開して、好きな場所に置くだけで使う形（インストーラーなし）。設定も exe のそばにあるほうが、見つけやすく、持ち運びやすい（フォルダごと移せる）
- 更新は、exe だけを置き換える手順（zip には `config.json` を入れない）。exe の隣に置いても、設定は消えない
- `%APPDATA%` は、隠れたフォルダの奥にあり、利用者が見つけにくい。アンインストールのときに、消し忘れも出る

## 選択肢
1. `%APPDATA%\coders-hub\config.json`（ADR 0019）のまま
2. exe と同じフォルダの `config.json`
3. 両方を読む（exe の隣を優先し、なければ `%APPDATA%`）

## 決定
2 を採用する。

- **配布版（exe）**: `coders-hub.exe` と同じフォルダの `config.json`。フック・チャネルサーバー・Hub は、すべて同じ exe から動くので、同じファイルを読む
- **環境変数 `CODERS_HUB_CONFIG`**: 指定すると、そのパスを使う（優先）。配布版でも開発時でも使える
- **開発時（`node` で起動）**: 既定ではファイルを読まない（`CODERS_HUB_CONFIG` を指定したときだけ読む）。`node.exe` の隣に置く意味がなく、リポジトリ内に個人の設定を置かないため
- 優先順位（環境変数 > 設定ファイル > 既定値）、内容（`internalPort`・`uiPort` だけ）、エラーの扱いは、ADR 0019 のまま
- ログ（`hub.log`）は、書き込みのたびに増えるファイルなので、`%LOCALAPPDATA%\coders-hub\` のまま（ADR 0020）。exe のフォルダは汚さない

ADR 0019 のうち、設定ファイルの置き場所だけを、この ADR で置き換える。

## 理由
- 設定が exe のそばにあり、見つけやすい。フォルダごと移せる
- 3 を採らないのは、読む場所が 2 つあると、どちらが効いているか分かりにくく、ポートがずれる原因になるため

## 影響・トレードオフ
- exe を、書き込めない場所（`Program Files` など）に置くと、設定ファイルを作れない。置き場所は、利用者が書き込めるフォルダにする（README に書く）
- exe を別の場所へ移すと、設定ファイルも一緒に移す必要がある。claude の設定には exe のパスを書いてあるので、移動時は設定を書き直すことになる（もともと必要）
- 旧版（ADR 0019 のとおり `%APPDATA%` を読んでいた版）は、まだ公開していないので、移行の手当ては不要
