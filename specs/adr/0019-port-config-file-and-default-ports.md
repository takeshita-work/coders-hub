# 0019: ポートは設定ファイル（config.json）でも変えられるようにし、既定を 47765 / 47766 にする

- ステータス: Accepted
- 日付: 2026-10-12

## 背景
ポートは、環境変数（`CODERS_HUB_INTERNAL_PORT`・`CODERS_HUB_UI_PORT`）でしか変えられず、既定は 8765 / 8766 だった。

- Hub・フック・チャネルサーバーは、別々のプロセスで、`claude` が起動する。環境変数は、`claude` を起動したシェルで決まるため、起動の経路によって値がずれ、フックとチャネルサーバーが別のポートを見る、気づきにくい不具合になりうる
- 8765 / 8766 は、Web 開発でよく使われる番号に近く、他のアプリと重なる可能性がある
- 画面を「アプリとしてインストール」すると、URL（ポート）に結びつくため、ポートは一度決めたら変えたくない
- 配布版（ADR 0018）は、開発者でない人も使う。環境変数の登録より、ファイルのほうが分かりやすい

## 選択肢
1. 環境変数のまま（既定だけ変える）
2. 設定ファイルを足す。優先順位は、環境変数 > 設定ファイル > 既定値
3. 設定ファイルだけにする（環境変数をやめる）

## 決定
2 を採用する。ユーザーの選択（2026-10-12）。

- **設定ファイル**: `%APPDATA%\coders-hub\config.json`。環境変数 `CODERS_HUB_CONFIG` でパスを変えられる。exe の隣には置かない（更新で exe を置き換えても残すため）
- **内容**: `{ "internalPort": 47765, "uiPort": 47766 }`。変えられるのはポートだけ。キーは省略できる。他のキーは無視する
- **優先順位**: 環境変数 > 設定ファイル > 既定値。環境変数は、テストと一時的な上書きのために残す
- **既定値**: 内部 **47765**、画面 **47766**（Windows が自動で割り当てるポート（49152 以降）より下で、よく使われるポートと重なりにくい）
- **エラー**: ファイルがなければ、無視する。JSON が壊れている・ポートが不正なときは、ファイルのパスを入れたエラーにする（黙って既定値に戻すと、ポートがずれるため）。フックは、いままでどおり、失敗しても `claude` を妨げない
- 3 つのプロセスは、同じ `loadConfig` を使うので、同じファイルを読む

## 結果
- 既定のポートが変わる。8765 / 8766 で使っていた人は、`config.json` に旧ポートを書くか、動いている Hub を止めて、新しい URL（`http://127.0.0.1:47766/`）を開く。「アプリとしてインストール」済みの人は、入れ直す
- 設定の置き場所が 1 つ増える。ただし、読む場所は `src/shared/config.mjs` の 1 か所
- 既存の ADR（0004・0012）の「8765 / 8766」は、当時の既定値の記録として残す
