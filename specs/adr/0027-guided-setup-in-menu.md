# 0027: セットアップは、案内のメニューで、手順を 1 つずつ表示して進める

- ステータス: Accepted
- 日付: 2026-10-12

## 背景
ADR 0026 で、チャネルサーバーは `claude mcp add` で登録することにした。セットアップは、次の手順になる。

- 使う claude のアカウントの確認 → `claude mcp add` → フックの追加 → 起動と確認

今のメニュー（ADR 0025）の「1」は、`setup` の出力（長い 1 つのテキスト）を表示するだけで、利用者は、読み解いて、コピーして、貼る必要がある。
手順の文面は、まだ固まっていない。テストと実機で確かめながら、直していきたい（ユーザーの要望、2026-10-12）。

## 選択肢
1. 今のまま、1 つのテキストを表示する
2. 手順を 1 つずつ表示し、利用者が進める（次へ・前へ・コピー）
3. 2 に加えて、`claude mcp add` などを、メニューから実行する

## 決定
2 を採用する。ユーザーの選択（2026-10-12）。3 は、実行結果の扱い（claude が PATH にない、アカウントの指定を誤るなど）と、確認の仕組みが要るので、この ADR では扱わない。

- **手順のデータは、1 か所**（`src/setup/steps.mjs`）に置く。1 つの手順は `{ id, title, body, copy? }`
  - `body`: 表示する行
  - `copy`: コピーできる内容（コマンド、JSON）。あれば本文のあとに表示する
  - exe のパスなどは、データを作るときに埋め込む（配布版は exe、開発時は node）
- **`setup`**: 手順を、テキストで出力する（今までと同じ使い方）。**`setup --json`**: 手順を JSON（`{ "steps": [...] }`）で出力する。メニューのスクリプトが読む
- **メニュー**（`guide.ps1`）
  - `1` セットアップを進める: `setup --json` を読み、手順を 1 つずつ表示する。操作: `Enter` 次へ、`b` 前へ、`c` `copy` の内容をクリップボードへコピー、`q` メニューへ戻る。最後の手順で `Enter` を押すと、メニューへ戻る
  - `2` フックの設定をファイルに保存する: `setup --write`（`coders-hub-hooks.json` だけ。`coders-hub.json`・`coders-hub-control.json` は、ADR 0026 でなくす）
  - `3` ログを開く（変更なし）
- 自動では実行しない。`settings.json` も書き換えない（ADR 0025 のとおり）

ADR 0025 のうち、メニューの `1`・`2` の内容を、この ADR で置き換える。

## 理由
- 利用者は、手順を 1 つずつ読み、コピーして、貼るだけで済む
- 手順の文面は、データだけを直せば変わる。`setup` の出力とメニューが、同じデータなので、食い違わない
- データと表示を分けるので、文面はユニットテストで、メニューの流れは PowerShell に入力を流すテストで確かめられる

## 影響・トレードオフ
- メニューのスクリプトが、JSON を読む処理を持つ（PowerShell 5.1 の `ConvertFrom-Json`）。exe の出力は UTF-8 で受ける
- `setup` の出力の形が変わる（手順ごとの見出しと、コピーできる内容）
- クリップボードのコピーは `Set-Clipboard`。コピーできない環境では、表示された内容を選んでコピーする
