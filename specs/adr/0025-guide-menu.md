# 0025: 案内のウィンドウに、設定の表示・保存とログを開くメニューを付ける

- ステータス: Accepted
- 日付: 2026-10-12

## 背景
ADR 0024 で、ダブルクリックしたときに案内のウィンドウを出すようにした。しかし、claude に入れる設定（フックと MCP）は、ターミナルを開いて `coders-hub.exe setup | more` を打たないと見られない。出力は 111 行あり、案内のウィンドウに全部を出すには長すぎる。ターミナルで起動するのは面倒（ユーザーの指摘、2026-10-12）。

## 選択肢
1. 案内に、`setup` のコマンドを1行足すだけ
2. 案内のウィンドウをメニューにする。選ぶと、設定の表示・ファイルへの保存・ログを開く、ができる。Enter だけで終了
3. `setup --apply` で、`settings.json` に自動で追記する

## 決定
2 を採用する。ユーザーの選択（2026-10-12）。3 は、設定ファイルを書き換える危険（壊す・元に戻せない）があるので、この ADR では扱わない。

- **メニュー**
  - `1` claude に入れる設定を表示する: `coders-hub.exe setup` の出力を、そのウィンドウに表示する。表示のあと、Enter でメニューに戻る
  - `2` 設定をファイルに保存する: `coders-hub.exe setup --write` を呼び、exe と同じフォルダに `coders-hub-hooks.json`・`coders-hub.json`・`coders-hub-control.json` を保存し、使い方（`--mcp-config` に渡すコマンドなど）を表示する
  - `3` ログを開く: `hub.log` をメモ帳で開く（まだなければ、その旨を表示する）
  - 何も入力せずに Enter: ウィンドウを閉じる（Hub は動き続ける）。ほかの入力は、メニューを再表示する
- **`setup --write [--out <フォルダ>]`**: 単独でも使える（ターミナルから）。保存先の既定は exe と同じフォルダ（開発時はいまのフォルダ）。同じ名前のファイルは上書きする（生成物のため）。保存できなかったときは、理由を表示して終了コード 1
  - 保存するのは、そのまま使える JSON だけ（コメントは付けない）。フックの設定は、`settings.json` の `hooks` に追加する内容。MCP の2つは、そのまま `--mcp-config` に渡せる
- **実装**: exe はウィンドウのない形式で、自分では対話できない（ADR 0020）。メニューは、案内のウィンドウの PowerShell スクリプト（`guide.ps1`）で動かす。本文は `guide.txt`、バッチは `guide.cmd`。いずれも `%LOCALAPPDATA%\coders-hub\` に、固定の名前で上書きする。スクリプトは UTF-8（BOM つき。Windows PowerShell 5.1 は BOM がないと ANSI として読むため）で、exe のパスとログのパスを埋め込む。コンソールの出力エンコーディングは UTF-8 にして、exe の出力を受ける
- **PowerShell の起動**: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File guide.ps1`。`-EncodedCommand` は使わない（ADR 0024 のとおり）。`-ExecutionPolicy Bypass` は、スクリプトの実行を許すために要る（クライアント版 Windows の既定は、スクリプトを実行できない）
- 表示（1）は、ページ送りをしない。111 行は、ターミナルのスクロールで見る（ページ送りは、対話の確認ができず、見送った）

ADR 0024 のうち、「案内の最後の行は Enter で閉じる旨だけ」の部分を、この ADR で置き換える。

## 理由
- ターミナルを開かずに、ダブルクリックだけで、設定の表示・保存まで進める
- 設定をファイルで保存できると、`--mcp-config` に渡すファイルが完成する。フックの設定だけが、貼り付けの作業として残る

## 影響・トレードオフ
- 案内のウィンドウが、メニューつきの小さな対話になる。操作が増える分、表示の仕組みが複雑になる（PowerShell のスクリプトを生成する）
- `-ExecutionPolicy Bypass` つきの PowerShell 起動は、ウイルス対策ソフトによっては警戒されることがある。コマンドは固定の文字列で、リモートのスクリプトは使わない
- `setup --write` が書き出した `coders-hub.json` などは、exe のパスを含む。exe を移動したら、`setup --write` をやり直す
- 開発時（`node` で起動）は、メニューを出さず、案内を、そのターミナルに出すだけ
