# 非機能要件

- ステータス: Draft（数値は仮置き。要確認）

| ID | 分類 | 要件 | 備考 |
|---|---|---|---|
| NFR-001 | 動作環境 | Windows 上で動作する | 他 OS は対象外（暫定） |
| NFR-002 | 規模 | 同時 30 セッションまで扱える | 一覧のグループ化・絞り込みが必要になる可能性（open-questions 参照） |
| NFR-003 | 性能 | 状態変化が一覧に反映されるまでの遅延は 3 秒以内 | フック通知を即時に画面へ反映する（WebSocket 等） |
| NFR-004 | 可用性 | Hub 本体が再起動しても、セッション一覧が自動で復元される | ポーリングのたびに自己情報を送る方式 |
| NFR-005 | 可用性 | Hub 本体は常に 1 プロセスのみ（多重起動しない） | ポート確保で排他 |
| NFR-006 | 運用 | セッションの登録・生存確認・終了検知が自動で行われる。閉じたセッション（強制終了を含む）は 1 分以内に一覧から外れる | 手動登録なし。強制終了はポーリング途絶で検知 |
| NFR-007 | セキュリティ | 外部公開は認証必須（MFA）。内部ポートは公開しない | `20-design/security.md` |
| NFR-008 | 互換性 | Claude Code のバージョンアップによる内部フォーマット変更の影響を局所化する | JSONL は補助用途に限定 |
| NFR-010 | 対応ブラウザ | PC の Chrome / Edge、およびスマホのブラウザ（レスポンシブ）で表示できる | Firefox / Safari は対象外。スマホのレスポンシブ対応は次の段階（REQ-006 の外部公開と同時）。MVP は PC のみ |
| NFR-009 | 保持 | 状態・イベント・指示の履歴は保存しない。Hub 本体はメモリのみで動作する | 再起動後はポーリングで一覧が復元される（NFR-004） |
